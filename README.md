# ChoreBoard

ChoreBoard is a sample iOS app I built for the CSCE 490 Research milestone to learn the technologies my team is using.

Users can add a chore, assign it to a roommate, and tap it to mark it complete. Chores are saved in a Supabase database, so they're still there after the app closes.

**Built with:** Swift, SwiftUI, Supabase, and supabase-swift (added with Swift Package Manager).
**To run:** open `ChoreBoard.xcodeproj` in Xcode, choose an iPhone simulator, and press Cmd+R. The app connects to my Supabase project, so it works without any setup.
**If the app shows a connection error,** my Supabase project may have paused from inactivity. Contact me at bjodom@email.sc.edu and I'll turn it back on.
